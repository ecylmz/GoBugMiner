# Changelog

## [1.0] - 2026-07-29

- Initial public release of GoBugMiner.
- Configurable GitHub evidence discovery and fix-revision resolution.
- Candidate BIC extraction and commit-, file-, and method-level metrics and
  labels.
- Provenance, checksums, validation, deterministic ordering, privacy defaults,
  and restart-safe execution.
- Explicit production-Go or all-changed SZZ path scope with shared source
  classification and recorded exclusions.
- Separate GitHub evidence and safely analyzable fix revisions with
  deterministic merge-strategy resolution.
- Final-validation completion semantics, UTF-8-safe Go parsing, null-preserving
  aggregate metrics, and revision-role label validation.
- Automated tests, Linux/macOS CI, documentation, deterministic offline
  reproduction, and a retained live validation snapshot.
