# Paper reproduction and validation evidence

This directory retains two distinct demonstrations for the Software Impacts
article.

`offline-reproduction-summary.json` is generated by
`scripts/reproduce_offline.sh` from two credential-free runs over a controlled
local Git history and pull-request fixture. The script validates both runs and
fails if any canonical research output differs.

The `gin-validation-*` files form a retained live validation snapshot for a
bounded `gin-gonic/gin` run. The YAML fixes the observation window, bug label,
privacy settings, and one-PR execution bound. The summary records the selected
pull request, GitHub merge and PR-head revisions, evidence and analysis fix
revisions, resolution policy, production-Go SZZ scope, excluded-path counts,
dependency versions, row counts, warnings, and validation result. This live
snapshot demonstrates external operation; it is not called deterministic
because GitHub and repository state can change.
